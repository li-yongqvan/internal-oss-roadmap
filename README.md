# internal-oss-roadmap

一个平级自由开源社区的**规划与追踪仓库**：怎么从零把社区建起来、每一步为什么这么定，全部公开记录。

> 社区本身没有中心门户——每个仓库由其 Owner 维护，参与者自发贡献。本仓库是规划工作的家，社区机制见 [《社区礼仪》](assets/05-community-etiquette.md)。

| 研究发现（含出处） | [assets/](assets/) |

## 方法

规划过程用 wayfinder 方式组织：每张票解决一个决策，地图只做索引；研究结论逐条附权威出处，不自编。
